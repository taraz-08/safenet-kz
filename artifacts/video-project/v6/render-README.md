# SafeNet KZ — рендер v6

Рендерер собирает **предоставленные** реальные снимки/записи сайта и озвучку. Он не открывает браузер, не обращается к ElevenLabs/Flow, не генерирует интерфейс, курсор или действия. Изображения Flow постоянно подписаны «Иллюстрация · Google Flow». Предыдущие снимки интерфейса v5 автоматически не используются.

## Запуск

Из корня репозитория, PowerShell. Проверенный установленный runtime из `artifacts/video-project/runtime.json`: Python 3.11, PyAV 12.3.0, Pillow 10.4.0, NumPy 1.26.4; доступны `libx264` и `aac`. Внешний ffmpeg не нужен.

```powershell
$videoPython = 'C:/Users/dimas/AppData/Local/Programs/Python/Python311/python.exe'
& $videoPython artifacts/video-project/v6/render.py --preview
& $videoPython artifacts/video-project/v6/render.py --source 'https://ВАШ-ДОМЕН' --capture-date '2026-10-25'
```

Укажите фактические домен и дату съёмки. По умолчанию дата честно отображается как неизвестная. Для Flow можно задать отдельные `source` и `date` в сцене, например «Google Flow · ранее созданная иллюстрация» и «Дата генерации не указана».

`--preview` создаёт **только** контактный лист, SRT и метаданные с суффиксом `-preview`, без MP4 и без требования озвучки. Все кадры помечены «ПРЕВЬЮ», недостающие изображения заменяются явной плашкой «Нет изображения для этой сцены». Это не выдаётся за съёмку работающего сайта. При отсутствии аудио длительность приблизительная: 2,5 слова/секунду.

Полный запуск проверяет каждую выбранную сцену **до кодирования**. Нет озвучки, аудио пустое/цифровая тишина, нет снимков/клипа — запуск прекращается с перечнем недостающих входов. Исключение для изображения: явно указанная `kind: "titlecard"`. Для intro/outro нужны настоящие Flow-файлы либо явный титр, отсутствие материалов не маскируется.

Между сценами применяется плавное растворение 0,4 секунды из последнего кадра предыдущей сцены. Пауза после озвучки берётся из `pauseAfterSec`, минимум 0,65 с. `durationSec` поддерживается как альтернативное имя минимальной длительности; для превью темп берётся из `voiceDirection.targetWordsPerMinute`.

## Входные файлы

```text
v6/
  render.py
  scenes.json
  inputvoice/intro.mp3, overview.mp3, ...
  shots/overview-01.png, overview-02.jpeg, ...
  clips/review.mp4                     # предпочтительнее снимков той же сцены
  flow/intro.mp4, outro.mp4
```

`scenes.json` — массив в нужном порядке; также принимается объект `{"scenes": [...]}`. ID уникальны, латинские буквы/цифры/`-`/`_`, до 80 символов. Перестановка массива меняет порядок монтажа, названия/число сцен не зашиты в код.

```json
[
  {"id":"intro","kind":"flow","title":"SafeNet KZ","text":"Текст русской озвучки вступления.","source":"Google Flow · иллюстрация","date":"Дата генерации не указана"},
  {"id":"overview","title":"Очередь проверки","text":"Текст озвучки текущей версии сайта.","source":"https://ваш-домен/#/review","date":"2026-10-25"},
  {"id":"outro","kind":"titlecard","title":"Решение принимает человек","text":"Текст заключения."}
]
```

Обязательны `id`, `title`, `text`. Остальные поля:

- `kind`: `ui` (обычно), `flow`, `titlecard` (или `title`). ID `intro`/`outro` и заканчивающиеся на `-intro`/`_outro` автоматически выбирают Flow, если `kind` не задан.
- `audio`: явный путь к озвучке. Иначе ищутся `inputvoice/{id}.mp3`, `.wav`, `.m4a`, затем такие же имена в `voice/`.
- `clip`: явный путь к записи UI; иначе ищется `clips/{id}.mp4`.
- `shots`: путь или массив путей. Без него выбираются `shots/{id}*.png/jpg/jpeg/webp` по имени. Используйте ID, не являющиеся префиксами друг друга, либо явный массив. Несколько снимков показываются равными долями сцены.
- `flow`: явный путь к иллюстрации. Иначе `flow/{id}.mp4`/`flow/intro.mp4`/`flow/outro.mp4`. Для intro/outro допускаются уже существующие `../v5/flow/intro-a.mp4` и `intro-b.mp4`: это отражается в метаданных. `--no-flow-fallback` отключает этот выбор.
- `duration`: минимальная длительность в секундах. Озвучка никогда не обрезается ради этого значения; добавляются 0,35 с перед ней и минимум 0,65 с после неё.
- `source`, `date` (или `capturedAt`): объявленные источник и дата, выводимые на экран. Дата изменения файла не выдаётся за дату съёмки.

Пути в сценах относительны папке `scenes.json`; абсолютные пути тоже принимаются. `--scenes PATH` выбирает другой сценарий. Используйте реальные снимки с хорошо читаемым масштабом интерфейса: рендерер сохраняет весь кадр без обрезки. Лёгкое движение снимков выполняется внутри панели. Записи воспроизводятся с исходной скоростью, затем удерживается последний кадр с подписью «Стоп-кадр записи работающего сайта». **Звук UI- и Flow-клипов отбрасывается**, используется только заданная озвучка.

## Одна длинная озвучка

По отдельному MP3 на сцену — предпочтительно. Запасной вариант:

```powershell
& $videoPython artifacts/video-project/v6/render.py --full-voice artifacts/video-project/v6/inputvoice/full.mp3 --alignment artifacts/video-project/v6/inputvoice/full.align.json
```

Разметка: `{"scenes":[{"id":"intro","start":0,"end":8.2}, ...], "words":[{"w":"Слово","s":0.4,"e":0.8}, ...]}`. Время — секунды в исходной озвучке. `words` необязательно. Границы нарезки должны включать все произнесённые слова соответствующей сцены. Отдельный файл сцены имеет приоритет над общей записью; пропущенная сцена без файла и разметки останавливает полный запуск.

Для отдельных MP3 необязателен соседний `{id}.align.json` с `words`: время относительно этого MP3, формат `w/s/e` или `word/start/end`. Без разметки SRT оценивается по количеству слов. С разметкой текстовые фразы распределяются по временным отметкам слов; это **не автоматическая проверка совпадения текста и речи**. Финальное совпадение и границы субтитров нужно просмотреть/прослушать. Метаданные отмечают использованный метод.

## Выход и производительность

`output/safenet-kz-jury-ru.mp4`: 1920×1080, 30 кадров/с, H.264 yuv420p, AAC stereo 48 кГц/192 кбит/с, faststart. Рядом `.srt`, `.contact-sheet.jpg` (все сцены), `.render.json` с длительностями, источниками, SHA-256 входов и признаком fallback Flow v5. `status: complete` появляется только после успешного MP4. Незавершённый файл имеет расширение `.partial.mp4`.

Кадры видео декодируются последовательно, озвучка читается небольшими блоками; полный видеоряд и звуковая дорожка не накапливаются в RAM. Между сценами декодеры закрываются. Это простой последовательный рендер **без кэша и автоматического возобновления**. Для быстрой проверки можно собрать одну сцену:

```powershell
& $videoPython artifacts/video-project/v6/render.py --preview --scene overview
& $videoPython artifacts/video-project/v6/render.py --scene overview --name overview-check
```

`--scene` повторяемый, порядок сохраняется из JSON. Другие параметры: `--output-dir PATH`, `--name NAME`, `--crf 19`, `--preset veryfast`, `--threads 4`, `--font PATH`, `--font-bold PATH`, `--voice-provider TEXT`. Число потоков ограничивает загрузку процессора. Для Linux по умолчанию ищется DejaVu Sans, для Windows Segoe UI. При смене текста необходимо заново подготовить соответствующую озвучку.

Состояние подготовки: медиаматериалы создаёт родительский агент после разрешения доступа; рендерер сам не обходит капчу и не загружает внешние данные.
