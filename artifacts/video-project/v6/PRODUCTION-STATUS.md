## План записи после восстановления доступа

1. Пульт: показать URL и реальные счётчики с датой записи.
2. Поиск Telegram: источники находок, просмотр каналов, причины срабатываний.
3. Карточка реального случая: цитаты, признаки, баллы и ссылка на исходный пост; признаки рекламы не называть доказанным мошенничеством.
4. Админ-доступ: скрыть ввод секретного кода из записи. Показать уже открывшийся режим и доступные действия. Не менять решения по реальным случаям ради видео.
5. Instagram/TikTok: показать фактические статусы доступа, включая ограничения, без обещания полного охвата.
6. Качество: показать агрегированные метрики и подпись, что выборка синтетическая; не выдавать её за точность на живом потоке.
7. Преимущества: объяснимый риск, очередь приоритетов, русский/казахский, происхождение находок, человек принимает решение.

Финальный MP4 создаётся только после получения актуальных кадров и новой озвучки. Отсутствующие материалы нельзя подменять вымышленным интерфейсом или старым демо без явной подписи.

## Последующее уточнение пользователя и результат

- Пользователь просит сначала статичные кадры, затем видео без заметных склеек, с русской озвучкой.
- Подготовлены и показаны `keyframes/01-start.png` и `keyframes/02-end.png`: встроенный imagegen, одинаковая камера и свет, аккуратное изменение положения карточек.
- После ручной проверки пользователя Flow запустил Veo 3.1 Lite (8 секунд, 10 кредитов), затем сообщил о неудаче и возврате кредитов. Факт возврата отдельно не проверялся.
- Попытка загрузить новые кадры через штатный выбор файлов остановлена: расширению ChatGPT в Edge требуется Allow access to file URLs. Пользователю передана точная инструкция; загрузка не состоялась.
- После сообщения пользователя о снятии запретов повторно проверены ElevenLabs и SafeNet. Сохранённая настройка или управляемая политика по-прежнему отклоняет доступ. Дальнейших обходов и повторов без изменения состояния не выполнялось.
- Рендерер учитывает запланированные паузы и добавляет плавные переходы 0,4 секунды. Подготовлен только контактный лист с явными заглушками недостающих материалов; финального MP4 v6 нет.
