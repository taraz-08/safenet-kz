# SafeNet AI — запуск и границы MVP

Новая платформа находится в `apps/console` (Next.js) и
`services/intelligence` (FastAPI). Существующий SafeNet KZ на Express и его
развёртывание Railway продолжают работать отдельно. Эта версия не заменяет
старый сайт до отдельного развёртывания новой инфраструктуры.

## Запуск на этом компьютере

Из корня проекта:

```powershell
.\Start-SafeNet-AI.ps1 -Install
```

Повторный запуск: ` .\Start-SafeNet-AI.ps1`; остановка:
` .\Start-SafeNet-AI.ps1 -Stop`.
Панель: <http://127.0.0.1:3000>. Документация API:
<http://127.0.0.1:8100/docs>.

Локальный запуск использует SQLite и настоящую очередь из четырёх рабочих
потоков. Только для этого запуска автоматически включается администратор;
оба процесса привязаны к `127.0.0.1`. Не открывайте такой режим в интернет.
Мониторы запускаются оператором после добавления публичных исходных ссылок.
Без ссылок отображается ожидание настройки, а не вымышленная активность.

## PostgreSQL, Redis и Celery

Нужен Docker с Compose. Скопируйте `.env.ai.example` в `.env.ai`, задайте два
разных случайных значения `POSTGRES_PASSWORD` и `SAFENET_ADMIN_CODE`, затем:

```sh
docker compose --env-file .env.ai -f compose.ai.yaml up --build -d
docker compose --env-file .env.ai -f compose.ai.yaml ps
docker compose --env-file .env.ai -f compose.ai.yaml logs --tail=100 api worker scheduler
```

Сервисы: console, api, worker (четыре процесса), scheduler, PostgreSQL, Redis.
Порты базы и брокера наружу не публикуются. Данные находятся в named volumes.
Для внешнего HTTPS-домена настройте `SAFENET_ALLOWED_ORIGINS`,
`SAFENET_SECURE_COOKIE=true` и публичный `NEXT_PUBLIC_WS_URL` при сборке
frontend; если WebSocket недоступен, работает опрос API с явным индикатором.
Не запускайте несколько экземпляров Celery beat. Серверные таблицы создаются
при первом запуске API; дальнейшие изменения схемы требуют миграций.

Контейнерная конфигурация подготовлена; если Docker отсутствует, её запуск
нельзя считать проверенным по результатам локальных SQLite-тестов.

## Как проверять

1. В URL Scanner вставьте одну публичную ссылку или текст. Ручной текст явно
   обозначается: источник независимо не загружался.
2. Задание сохраняется в `scan_tasks`; очередь выполняет сбор, извлечение,
   анализ и сохранение. WebSocket передаёт реальные снимки состояния.
3. Откройте результат: цитаты, веса, сумма, ограничения и исходный URL.
4. Аналитик выбирает «признаки подтверждены», «ложное срабатывание» или
   «нужен контекст». Подтверждение признаков не является юридическим вердиктом.
5. Создайте Markdown-отчёт или экспортируйте JSON. Чат объясняет выбранную
   проверку, ссылаясь на её сохранённые данные.
6. В AI Browser Agents добавьте ссылки отдельно для TikTok, Instagram,
   YouTube, Threads и Telegram. Start/Stop/Restart управляют сохранёнными заданиями.
   Мониторы обходят заданные источники и найденные публичные ссылки, в том числе
   между площадками: например, Instagram → Threads. После успешного Live-сбора
   добавляется до 10 адресов на каждый включённый монитор, максимум 100 в его
   списке. Остановленные мониторы и их настройки не меняются; интервалы и паузы
   после ограничения доступа сохраняются. Происхождение ссылки записывается
   в журнал; балл и владелец исходного аккаунта ей не приписываются.
   Ручной текст, загруженные файлы и Demo не расширяют Live-обход.
   Это ограниченный обход источников, а не поиск всей социальной сети.
   Страницы входа, регистрации и навигации не добавляются в очередь; параметры
   отслеживания удаляются, повторные адреса одного материала объединяются.

После запрета доступа монитор ждёт минимум 15 минут. Остановка отменяет
очередь этого агента; поздний результат текущей загрузки не сохраняется.
История и журналы удаляются по `SAFENET_RETENTION_DAYS` (по умолчанию 30).
Полные платёжные номера и телефоны редактируются до сохранения/LLM.

## Реальные данные и Demo Mode

Live — только введённые пользователем материалы и реально полученный публичный
контент. Demo — отдельная выборка записей с меткой `mode=demo`; примеры
появляются только по явному запуску. Они не входят в Live-счётчики.

Перенос старых публичных находок выполняется отдельно, без сетевых запросов:

```powershell
cd services/intelligence
.\.venv\Scripts\python.exe -m safenet.import_legacy ..\..\data\cases.json
```

Импорт пропускает demo, неизвестное происхождение и повторы URL. Он сохраняет
исходную дату и пометку исторического материала, пересчитывает новый анализ,
не утверждая, что страница только что проверена. Старые файлы не изменяются.

## AI и доступ к платформам

Детерминированные правила работают без ключа на русском, казахском и английском.
Они покрывают пирамиды, инвестиционные обещания, фишинг, платные розыгрыши,
подозрительные магазины, вакансии, имитацию организаций и рекламу казино.
Kaspi, Halyk и eGov сами по себе не увеличивают риск. Балл — сумма проверяемых
признаков в диапазоне 0–100, а не вероятность мошенничества.

Для OpenAI-совместимого LLM задайте `SAFENET_LLM_BASE_URL`,
`SAFENET_LLM_API_KEY`, `SAFENET_LLM_MODEL`, опционально
`SAFENET_LLM_PROVIDER`. Модель выбирает порядок уже найденных признаков и
рекомендаций, не создаёт новые доказательства и не меняет балл. При ошибке
провайдера анализ правил сохраняется, статус ошибки остаётся видимым.
Не отправляйте этому провайдеру приватные переписки или секреты.

Локальный запуск автоматически обнаруживает уже работающий Ollama с моделью
`qwen3-vl:2b-instruct`. Эта интеграция проверена реальными запросами на русском,
казахском и английском; данные остаются на компьютере. Если локального сервера
нет, работа правил не прерывается. Уже заданные переменные LLM имеют приоритет.

Сбор публичных документов использует проверку каждого адреса DNS, закрепление
соединения за проверенным IP, проверку каждого редиректа и предел размера/времени.
Размер документа ограничен 2 МиБ; только для точных хостов `youtube.com`,
`www.youtube.com`, `m.youtube.com` — 8 МиБ, поскольку публичная страница канала
может превышать 2 МиБ. При редиректе лимит выбирается заново для нового хоста.
Публичный JSON внутри уже полученной страницы Instagram/YouTube/Threads разбирается
без выполнения JavaScript и только при совпадении идентификатора источника.
Сервисный текст платформы, счётчики подписчиков и один заголовок не считаются
полученным содержанием публикации.
Для Threads проверяются имя автора, код поста, canonical URL и публичность.
Профиль без содержательной биографии может предоставить до 20 собственных
постов из открытого предпросмотра; ответы, цитаты чужих постов и рекомендации
не собираются. Приглашение войти для просмотра дополнительных записей не скрывает
уже видимый публичный текст; настоящая стена входа, CAPTCHA и приватность
останавливают проверку. Контактная заглушка Telegram не получает оценку риска.
Playwright отображает уже полученный статичный документ без JavaScript и без
самостоятельного сетевого доступа. Для YouTube можно указать
`SAFENET_YOUTUBE_API_KEY`: тогда доступные видео/каналы проверяются через
официальный Data API.

Обработка видео и звука подключена к новой платформе: Whisper small распознаёт речь,
Tesseract — текст на шести выбранных кадрах, а локальный Qwen-VL может добавить
описания визуальных сцен. Балл рассчитывается по словам из речи/OCR и текста страницы;
модельные описания не увеличивают риск. Цитаты снабжены таймкодами, повторение рекламы
не увеличивает балл. Проверяется максимум первые 120 секунд и первая звуковая дорожка.

На странице сканера есть загрузка видео/аудио до 64 МиБ. Результат помечается как
загруженный оператором; указанная им ссылка не подтверждает происхождение файла.
Публичные Instagram/TikTok permalink-ссылки дополнительно проверяются на доступный MP4.
Профиль сам по себе не даёт доступ ко всем роликам: нужны обнаруженные публичные
ссылки на публикации. Требование входа, CAPTCHA и приватность не обходятся. Если
видео недоступно, это видно в карточке; обработка одного описания не выдаётся за
обработку ролика. Недоступный материал не получает нулевой балл «за безопасность».

Зависимости устанавливаются из `services/intelligence/requirements.lock.txt`.
Whisper использует локальную папку `data/models/faster-whisper-small` (model.bin,
config.json, tokenizer.json, vocabulary.txt); автоматического скачивания модели во
время проверки нет. OCR использует `npm ci` и `npm run setup:ocr` в корне проекта.
`SAFENET_MEDIA_ENABLED=false` отключает обработку; `SAFENET_WHISPER_MODEL` задаёт путь
модели. Необязательные описания кадров: `SAFENET_VISION_URL` и `SAFENET_VISION_MODEL`.
Пустое значение отключает их. Health показывает наличие зависимостей, а карточка —
фактический успех каждой обработки. На CPU короткий ролик может занимать несколько
минут; рабочий процесс ограничен 300 секундами и одной одновременной обработкой на
общей папке медиа. В Compose эта папка общая у API/worker, модели монтируются read-only;
описание сцен через Ollama в Compose отключено по умолчанию. Поддерживается только
локальный loopback-сервис модели. Локальный запуск проверен отдельно
от Docker: сборка контейнера не означает подтверждённую работу модели.

Исходники и кадры хранятся в `runtime/media` до удаления истории по сроку хранения;
кадры доступны администратору. Текст редактируется для сокрытия платёжных реквизитов,
но изображения не обезличиваются автоматически. Видео декодируется только из локального
файла, без внешних ссылок из контейнера. Скачивание ограничено разрешёнными CDN,
проверкой DNS/IP/редиректов, размером, временем и сигнатурой MP4.

**Пока не реализовано:** автономная навигация Browser Use, полноценная загрузка
динамических лент, трансляция браузеров и непрерывная обработка прямых эфиров.
Шесть кадров могут пропустить короткую вставку; распознавание речи/OCR ошибается.
Даже нулевой балл не подтверждает безопасность. Старые проверки сохраняют прежний
охват — только доступный текст и метаданные.

## Проверка качества

```powershell
cd services/intelligence
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe evaluate.py
cd ../../apps/console
npm.cmd run typecheck
npm.cmd test
npm.cmd run build
```

Python-анализатор — отдельный набор правил. Его примеры разработчика нужны для
регрессий, а не для заявления точности на реальном потоке. Метрики старого
движка (в том числе precision 85,5%) нельзя переносить на эту версию.
Старая отложенная выборка не читается для настройки. `npm run evaluate` из
корня по-прежнему пересчитывает только старый анализатор.
