# Matt Pocock в SafeNet KZ

Источник навыков: [mattpocock/skills — Skills for Real Engineers](https://github.com/mattpocock/skills), ревизия `5beb35b`. Это инструкции для агента разработки, а не библиотека анализатора и не браузерное расширение.

В Codex установлены `setup-matt-pocock-skills`, `tdd`, `code-review`, `codebase-design`, `domain-modeling`, `to-tickets`. Каталог установки — `$CODEX_HOME/skills` (по умолчанию `~/.codex/skills`). При переносе на другой компьютер навыки нужно установить отдельно из официального репозитория. Код сайта не зависит от их наличия во время работы.

Проект использует существующие настройки:

- GitHub Issues `taraz-08/safenet-kz` — задачи и спецификации, см. [issue-tracker.md](issue-tracker.md).
- `GLOSSARY.md` и `docs/adr/` — язык предметной области и архитектурные решения.
- Поведенческие тесты на границе HTTP API и модулей: воспроизвести ошибку, исправить, проверить регрессии.
- Ревью по требованиям брифа и правилам репозитория. Гипотезы о качестве проверяются метриками; отложенные строки не используются для настройки.

Установка навыков сама по себе не означает, что все пункты брифа реализованы: ограничения и незавершённые работы отражены в GitHub Issues и методике. Развёртывание описано в [RAILWAY.md](../RAILWAY.md).
