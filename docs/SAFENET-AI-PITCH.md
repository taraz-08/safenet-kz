# Демонстрация SafeNet AI — пять минут

**0:00–0:35 — задача.** Публичные публикации содержат признаки финансовых
пирамид, фишинга, платных розыгрышей и скрытого продвижения казино.
SafeNet помогает аналитику определить, что проверить раньше. Юридическое
решение не автоматизируется.

**0:35–1:10 — Overview.** Показать Live Mode, дату и историю. Если загружен
архив старого SafeNet, назвать его ранее собранными реальными материалами.
Счётчики строятся из базы; отсутствие новых проверок не скрывается.

**1:10–2:00 — агенты.** Открыть четыре монитора, указать публичные источники,
запустить. Показать фактический журнал: очередь, загрузка, извлечение, анализ,
сохранение. При запрете доступа показать ошибку и отсутствие балла.
Статичный сбор не выдавать за просмотр видео или полный охват сети.

**2:00–3:00 — проверка.** Открыть URL Scanner. Для воспроизводимого показа
отдельно выбрать Demo Mode и пример с запросом SMS-кода или гарантированной
доходностью. Показать точную цитату и вес. Сравнить с обычным упоминанием
Kaspi или предупреждением о мошенниках. Вернуться в Live Mode и показать,
что синтетическая проверка не попала в реальные счётчики.

**3:00–3:45 — решение человека.** Открыть сохранённый случай. Обсудить
контекст, выбрать решение только после реальной проверки. Создать отчёт и
показать исходную ссылку. Чат объясняет сохранённые признаки; если включён
LLM, показать его фактический статус, если нет — честно назвать режим правил.

**3:45–4:20 — архитектура.** Next.js → FastAPI → очередь → публичный сбор →
правила/опциональный LLM → PostgreSQL → аналитик. Четыре рабочих процесса
в контейнерном режиме; SQLite и потоки для локального старта. Упомянуть SSRF,
изоляцию Demo/Live, вход администратора, журнал и срок хранения.

**4:20–5:00 — качество и развитие.** Показать реальные результаты тестов.
Объяснить отличие регрессионных примеров нового движка от независимой
оценки качества. Следующие шаги: независимая разметка, разрешённые API
платформ, безопасная динамическая навигация Browser Use и обработка эфиров.
Преимущества: проверяемые цитаты, русско-казахско-английский анализ,
сохранённая история и приоритетная ручная проверка.
