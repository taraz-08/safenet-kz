# SafeNet KZ 4.0.0 — ИИ, видео + дыбыс / ИИ, видео + звук

**Қазақша.** Алдын ала үйретілген **Qwen3-VL 2B Instruct** Instagram кадрындағы көріністі және Whisper таныған сөйлеудің мәнмәтінін жергілікті талдайды. OCR мәтінді, OpenCV QR-кодты оқиды. Белгіде түпнұсқа сөздер, уақыт және ИИ пайымы бөлек көрсетіледі. Бұл таңдаулы кадрлар мен дауыс үзінділерін тексеру; барлық видеоны толық қамтуға немесе әрбір логотипті тануға кепілдік жоқ. [ИИ 4.0 нұсқаулығы](AI-4.md).

**Русский.** Уже обученная **Qwen3-VL 2B Instruct** через локальный Ollama оценивает видимый кадр Instagram и контекст речи, расшифрованной Whisper. OCR читает надписи, OpenCV декодирует QR. Правила и модель ищут признаки риска, а также контекст рекламы, новости или предупреждения. Распознанная цитата и визуальное предположение ИИ показываются отдельно. Проверяются выбранные кадры и фрагмент речи, а не каждое мгновение ролика. [ИИ 4.0: устройство и установка](AI-4.md).

## Жергілікті өңдеу / Локальная обработка

**Қазақша.** Микрофон қолданылмайды: дыбыс тек таңдалған Instagram қойындысынан алынады. Браузердегі capture ағынының кадры видео аумағына қиылып, жергілікті `127.0.0.1:4310` серверіне жіберіледі. Кадр мен дыбыс бұлтқа жіберілмейді және дискке немесе кейстер базасына сақталмайды. Қысқа фрагменттер өңдеу кезінде жедел жадта болады. Модельдерді алғашқы орнату интернетті қолданады; танудың өзі жергілікті орындалады.

**Русский.** Микрофон не используется: звук берётся только из выбранной вкладки Instagram. Кадр потока захвата обрезается до области видео и передаётся локальному серверу `127.0.0.1:4310`. Кадры и звук не отправляются в облако и не сохраняются на диск либо в базу кейсов. Короткие фрагменты находятся в оперативной памяти во время обработки. Первичная загрузка моделей использует интернет, само распознавание выполняется локально.

Кадр шегі / лимит кадра: **1,5 МБ**. Дыбыс шегі / лимит аудио: **2 МБ**, бір API-үзінді / один API-фрагмент — не более **30 секунд**. Бір уақытта бір тапсырма, кезекте ең көбі екі тапсырма орындалады. / Одновременно выполняется одно задание, ещё максимум два ожидают в очереди.

## Нәтижені сақтау / Сохранение результатов

**Қазақша.** Бастапқы кадр/аудио сақталмайды. Автосақтау қосылса, қауіп шегіне не кілт сөзге сәйкес нәтиже кейске жазылады: URL, дереккөз, уақыт, кадр/дауыс/QR мәтіні және ИИ пайымы. ИИ моделі мен оның пайым екенін білдіретін белгі де сақталады. Жаңа орнатылымда автосақтау өшірулі, бастапқы шек 60; осы жұмыс орнында бөлек қосылып, 30 болып таңдалған.

**Русский.** Сырые кадры и аудио не сохраняются. При включённом мониторинге результат, удовлетворяющий порогу риска или ключевой фразе, может стать кейсом. Сохраняются URL, источник, время получения/захвата, фрагменты `frame`/`audio`/`qr` и отдельные `vision`-наблюдения с `method:model_inference`, именем модели и `startMs`/`endMs`. ИИ-описание не становится исходной цитатой. При выключенном мониторинге результат не сохраняется. Новый экземпляр имеет `enabled:false,minScore:60`; в этой рабочей установке отдельно выбраны `enabled:true,minScore:30`.

Постоянный URL и Origin расширения проверяются, но публичная видимость аккаунта не доказывается (`publicVisibilityVerified:false`). Личные сообщения не включаются. JSON-экспорт кейса содержит SHA-256 канонического `payload`; он позволяет проверить целостность JSON, а не истинность содержимого, реальность захвата или личность автора. Неизменённые распознанные строки могут содержать ошибки OCR/ASR.

## Модельді жаңа компьютерге орнату / Установка модели на новом компьютере

4.0 нұсқасы **`qwen3-vl:2b-instruct`** (шамамен **1,9 ГБ**) және Whisper small модельдерін қолданады. Олар алдын ала үйретілген; осы бағдарламада пайдаланушы деректерімен қайта оқыту жүргізілмейді. / В 4.0 используются уже обученные **`qwen3-vl:2b-instruct`** (примерно **1,9 ГБ**) и Whisper small. Дополнительное обучение на пользовательских данных не выполняется. Выбран именно тег `-instruct`. [Подробности ИИ](AI-4.md).

Басқа компьютерде PowerShell-ді жоба бумасында ашыңыз. Python 3.11 және Node.js 22.12+ қолданылады. / На другом компьютере откройте PowerShell в корне проекта. Используются Python 3.11 и Node.js 22.12+.

```powershell
npm.cmd ci --no-audit --no-fund
npm.cmd run setup:ocr
python -m pip install faster-whisper==1.2.1 opencv-python-headless
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-media.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup-ai.ps1
```

**Қазақша.** Скрипт ресми `Systran/faster-whisper-small` репозиторийінің бекітілген ревизиясынан шамамен **486 МБ** модельді `data/models/faster-whisper-small` бумасына жүктейді. Python басқа жерде болса, `SAFENET_PYTHON` айнымалысына оның толық жолын беріңіз. Дыбыс worker-і кейін интернеттен модель іздемейді: файл жоқ болса, нақты қате қайтарады.

**Русский.** Скрипт загружает примерно **486 МБ** из закреплённой ревизии официального репозитория `Systran/faster-whisper-small` в `data/models/faster-whisper-small`. При другом пути Python задайте его через `SAFENET_PYTHON`. Рабочий процесс распознавания не загружает модель автоматически: при отсутствии файлов возвращает явную ошибку.

Whisper CPU **int8** режимінде іске қосылады. GPU драйверін баптау қажет емес. `faster-whisper` дыбысты PyAV арқылы ашады, жеке `ffmpeg.exe` талап етілмейді. / Whisper использует CPU **int8**, настройка GPU не нужна; декодирование выполняет PyAV, отдельный `ffmpeg.exe` не требуется. [faster-whisper](https://github.com/SYSTRAN/faster-whisper), [модель / модель](https://huggingface.co/Systran/faster-whisper-small/tree/main).

Qwen3-VL жергілікті Ollama арқылы жұмыс істейді; оның қолжетімділігі мен нақты күйі SafeNet мониторинг бетінде көрсетіледі. / Qwen3-VL работает через локальный Ollama; установщик проверяет архив и издателя, а SafeNet при запуске поднимает установленный движок. Папки: `data/runtime/ollama` и `data/models/ollama`. При отсутствии модели/движка ИИ явно отмечается недоступным, доступные OCR/QR/Whisper продолжают работу.

OpenCV QR не требует загрузки нейросетевой модели, но требует установленного Python-пакета. При его отсутствии кадр может быть обработан OCR с явным сообщением о неполном QR-покрытии. Найденный QR — текстовая улика, а не доказательство безопасности/опасности ссылки.

## Шектеулер және тексеру күйі / Ограничения и статус проверки

**Қазақша.** Qwen3-VL қолжетімді болса, мәтінсіз көріністі де бағалайды, бірақ ұсақ логотип, жылдам жарнама кірістірмесі, музыка, нашар дыбыс және аралас тілдер қате не өткізіп алуға әкелуі мүмкін. Модель қолжетімсіз болса, мәтінсіз нысандарды талдау орындалмайды және бұл күйде көрсетіледі. Казиноның көрінуі жарнама не алаяқтық дәлелі емес; жаңалық/сақтандыру мәнмәтінін тексеріңіз. Төмен балл қауіпсіздік кепілі емес.

**Русский.** При доступной Qwen3-VL визуально оцениваются и объекты без читаемого текста. Это предположение небольшой модели: мелкие логотипы, краткие рекламные вставки, плохой звук, музыка и смешанные языки могут быть пропущены или истолкованы ошибочно. Если модель недоступна, визуальная оценка не выполняется и статус сообщает об этом. Казино в кадре не доказывает рекламу или мошенничество; важен контекст новости/предупреждения. Низкий балл и отсутствие распознанной речи не означают безопасность.

Для текущего кода выполняются `npm.cmd test` и `npm.cmd run build`. **69 тестов расширения** прошли в отдельном запуске разработки 4.0: [отчёт](../qa/extension-v4-tests.txt). Эти проверки не подтверждают живой захват Instagram 4.0 и не измеряют точность на реальных казахских роликах.
