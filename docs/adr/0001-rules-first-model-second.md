# Правила объясняют, модель только добавляет один помеченный признак

Бриф ставит объяснимость выше «чёрного ящика» (20% оценки), поэтому балл риска считают взвешенные правила с цитатами, а n-граммная модель добавляет к ним не больше одного признака с весом 30–45 и пометкой «только модель». Одна нейросеть дала бы больше recall, но аналитик не увидел бы, почему материал помечен. В живом автопоиске (Telegram, Instagram, TikTok) учитываются только признаки правил: на реальных лентах баллы «только модель» давали слишком много ложных срабатываний на новостях и вакансиях.
