# Итоговые метрики считаются только на нетронутой половине слепой выборки

Слепую выборку (330 примеров) написал отдельный агент по брифу, не видя правил. Она детерминированно делится по `sha256(id)` на validation, где разбирают ошибки и обучают модель, и holdout, который никто не читает построчно и по которому правила не настраивают. Первый прогон замороженного движка сохранён отдельно (`data/metrics-blind-first-run.json`). Так цифры для жюри честнее, хотя ниже, чем 100% на dev-наборе, писавшемся вместе с правилами.
