# SafeNet AI: Railway + локальная обработка медиа

Конфигурация 27 октября 2026 года. Cloud image: `deploy/railway/Dockerfile`.

## Разделение работы

- Railway: публичные источники Telegram, Instagram, TikTok, YouTube и Threads,
  анализ полученного текста, очередь проверок, граф связей и доступ по коду.
- Локальный запуск `Start-SafeNet-AI.ps1`: дополнительно OCR изображений,
  распознавание речи и описание выбранных кадров локальной Qwen3-VL.
- Облачный сервер не скачивает видео и не принимает файлы на обработку.
  При выключенном компьютере локальная обработка медиа недоступна.
- Сбор останавливается при запрете доступа, требовании входа или CAPTCHA.
  Непроверенное видео не получает отметку безопасности по отсутствию текста.

## Запуск

Один контейнер и одна реплика: Next.js принимает запросы на `PORT`, FastAPI
слушает `127.0.0.1:8100`. Маршруты `/api/v1/*` проходят через Next. Интерфейс
обновляется опросом API. Supervisor завершает контейнер при отказе любого сервера;
Railway перезапускает его. Sleep отключён. Healthcheck: `/api/v1/health`.

SQLite находится в `/data/ai/safenet.db` на существующем томе. Старые файлы
SafeNet KZ в `/data` сохраняются. Они автоматически не превращаются в новые
проверки AI. Новая база создаётся атомарно; пять мониторов запускаются с открытыми
URL из `initial-monitoring.json`, первые обращения разнесены по времени. Интервал
каждого монитора — 1800 секунд. Найденные поддерживаемые ссылки пополняют его
список. Это обход доступных источников и связанных ссылок, не поиск всей соцсети.

Повторный запуск сохраняет остановленные мониторы, настройки, очередь и курсор
источников. Незавершённые задачи локальной очереди восстанавливаются под теми же
ID. Требуется одна реплика и один API worker.

Текущий том — 100 МБ, поэтому медиа в нём не сохраняется; облачная история имеет
срок хранения 7 дней. Перед существенным ростом потока нужно увеличить том и
перейти на PostgreSQL/отдельную очередь; заполнение диска не является решённой
задачей бесконечного хранения. Локальная история по умолчанию хранится 30 дней.

## Доступ и обновление

Сохраняется существующая переменная `SAFENET_ADMIN_CODE`; код не включён в Git.
`SAFENET_LOCAL_ADMIN=false`, secure HttpOnly cookie, разрешённый origin —
`https://safenet-kz.up.railway.app`. Гостям доступно чтение; изменения требуют входа.
Локальный запуск привязан к loopback и явно подписан как локальный администратор.

Сборка с корня: `docker build -f deploy/railway/Dockerfile .`.
Start command: `/app/deploy/railway/entrypoint.sh`.
Docker локально отсутствует: фактическая проверка контейнера выполняется сборкой
и healthcheck Railway; Python/Next тесты не заменяют такую проверку.
