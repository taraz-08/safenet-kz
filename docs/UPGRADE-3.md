# SafeNet 3.0 — бақылау және зерттеу / мониторинг и исследование

## Что работает

- Новый стеклянный интерфейс на русском и казахском, адаптированный для телефона.
- **Мониторинг**: автоматическое сохранение результатов расширения по баллу или ключевым словам. До 20 фраз, до 5000 кейсов, 30 последних наблюдений. Одновременное совпадение не создаёт дубликат: одинаковые URL и нормализованный текст обновляют счётчик повторов. Автосохранение отключено по умолчанию; включается на странице мониторинга. В рабочей установке можно включить его отдельно.
- **Медиа**: существующие локальные OCR и Whisper дополнены OpenCV QR. Сохраняются распознанный текст, источник и время фрагмента; сырые кадры и звук не сохраняются. QR не открывается автоматически. При недоступности OpenCV результат явно сообщает неполное покрытие.
- **Исследование ссылок**: проверка публичных HTTP(S) ссылок, цепочки HTTP-перенаправлений и конечного адреса. Сравнение desktop/mobile User-Agent проводится с одного компьютера. Разница ответов — наблюдение, не доказательство клоакинга. JavaScript и meta-refresh не выполняются. Максимум 5 переходов на вариант, 8 секунд суммарно, 256 КиБ ответа; каждый DNS-адрес проверяется, соединение закрепляется за проверенным адресом.
- **Доказательства**: JSON с цитатами, наблюдениями, методом сбора, временем и SHA-256. Хэш подтверждает целостность экспортированного JSON, а не подлинность исходной публикации.
- **Граф**: общие домены, упоминания и строки, похожие на адреса кошельков. Совпадение не определяет владельца; блокчейн и контроль адресов не проверяются.
- **Meta Ad Library**: публичный поиск по стране/запросу; опциональный официальный API-коннектор. Ключи не нужны для остальных функций.

## Қалай пайдалану керек

1. `start.cmd` арқылы SafeNet-ті ашыңыз. «Бақылау» бетінде автосақтауды және қауіп шегін таңдаңыз, ережелерді сақтаңыз.
2. Chrome-да бұрын орнатылған SafeNet кеңейтімін бір рет қайта жүктеп, Instagram/TikTok бетін жаңартыңыз. Жаңа нұсқа — **3.0.0**.
3. Көрінетін жазбалар автоматты тексеріледі. Қолдау көрсетілетін Instagram лентасында «Автоайналдыру» келесі жазбаға өтеді. Қойынды фокуста болуы қажет. Қауіп белгісі табылса, айналдыру тоқтайды.
4. Видеоға арналған кадр/дауыс режимі кеңейтімдегі бөлек батырмамен қосылады. Chrome рұқсатынсыз дыбыс түсірілмейді; микрофон қолданылмайды.
5. «Кейстер» бетінде себеп, дәл дәйексөз және JSON есебін ашыңыз. «Сілтемелер» бөлімінде сыртқы мекенжайдың бағыттауларын тексеріңіз.

## Официальный API Meta

Скопируйте `.env.example` в `.env` и укажите выданный вам токен и версию API вашего приложения. Перезапустите сервер. Интерфейс показывает «настроено», пока доступ не проверен реальным запросом. Самостоятельная покупка подписок и регистрация приложения Meta не выполняются.

По [официальной документации Meta](https://br-fr.facebook.com/ads/library/api/), API охватывает политическую/общественную рекламу по миру за 7 лет и все категории, показанные в ЕС/Великобритании, за последний год. Поэтому запрос всех коммерческих объявлений Казахстана через этот API не поддерживается нашим коннектором. Для публичной библиотеки доступна отдельная ссылка. Ни один из этих режимов не гарантирует полноту всех показов.

Запрос ограничен 100 символами; один ответ — максимум 25 записей, 512 КиБ и 10 секунд. Токен передаётся в заголовке только `graph.facebook.com`; страницы пагинации автоматически не открываются. Коннектор не публикует рекламу и не меняет рекламные кампании.

## Что не подключено

Нет обхода закрытых сообщений/аккаунтов, круглосуточного сбора всего Instagram через тысячи IP, модели распознавания логотипов/слотов без текста, многорегионального прокси-анализа, идентификации людей или автоматической государственной блокировки. Для этих задач нужны другие данные, модели, доступы и проверенная точность. Наличие кнопки или настроек не доказывает успешный захват в Chrome.

Архитектурные ориентиры: [Kaspersky DFI](https://media.kaspersky.com/documents/Kaspersky_Digital_Footprint_Intelligence_v.2025.pdf) — поиск и аналитика цифровых рисков; [ZeroFox](https://www.zerofox.com/terms-and-transparency/information-on-content-removal/) — запросы на удаление от имени клиента, а не самостоятельная власть удалить любой аккаунт. SafeNet не подключён к этим платным сервисам.

Распознавание QR использует [OpenCV QRCodeDetector](https://docs.opencv.org/4.x/de/dc3/classcv_1_1QRCodeDetector.html). В текущей установке OpenCV уже доступен; отдельная загрузка модели для QR не требуется. Для нового компьютера нужен Python-пакет `opencv-python-headless` вместе с зависимостями медиа режима.

## Проверки

`npm.cmd test`, `npm.cmd run evaluate`, `npm.cmd run build`; `npm.cmd run verify:qr` выполняет реальный OCR/OpenCV на синтетическом QR из `qa/qr-fixture.png`. Итог — `qa/qr-verification.json`. Это тест локального распознавания, а не запись реального Instagram.
