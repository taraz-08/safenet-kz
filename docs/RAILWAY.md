# Развёртывание SafeNet KZ на Railway

Репозиторий: `taraz-08/safenet-kz`, ветка `main`. Сборка, запуск и проверка готовности задаются в настройках сервиса Railway через плагин или панель управления.

На 25.10.2026 Railway больше не разрешает подключать `railway.json` / `railway.toml` к новым сервисам. Поэтому устаревший файл удалён из репозитория. Для будущего управления инфраструктурой из кода используется `.railway/railway.ts`; при работе в общем проекте нужен именованный partial, чтобы не менять другие сервисы.

| Настройка сервиса | Значение |
|---|---|
| Builder | Railpack |
| Root Directory | `/` |
| Build Command | `npm run build` |
| Start Command | `npm start` |
| Healthcheck Path | `/api/health` |
| Healthcheck Timeout | 120 секунд |
| Restart Policy | On Failure, максимум 3 попытки |

## Настройка сервиса

1. Подключить GitHub-репозиторий к сервису Railway. Корень проекта — `/`.
2. Railpack устанавливает зависимости из `package-lock.json`, затем запускает `npm run build`. Для сборки нужны devDependencies: Vite и языковые пакеты OCR. Не задавать `NPM_CONFIG_PRODUCTION=true` или `NPM_CONFIG_OMIT=dev` на этапе установки.
3. Добавить Volume с точкой монтирования `/data`. Приложение использует `RAILWAY_VOLUME_MOUNT_PATH` для случаев, решений аналитика и состояния поисковых модулей. Не монтировать Volume поверх `/app/data`: там находятся модель, метрики и синтетический корпус из репозитория.
4. Для полного рабочего места задать секрет `SAFENET_ACCESS_KEY` в Variables. Сайт запросит HTTP Basic: любое имя пользователя и этот ключ в качестве пароля. Использовать только HTTPS; ключ не записывать в Git.
5. Создать публичный домен Railway. `PORT`, адрес прослушивания `0.0.0.0` и домен определяются автоматически. Healthcheck: `/api/health`, ожидается HTTP 200 и `ok:true`.
6. Оставить одну реплику: JSON-хранилище не рассчитано на одновременную запись несколькими процессами. Для нескольких реплик нужен переход на БД (GitHub Issue #7).

Без ключа сайт работает в режиме `public_read_only`: посетители видят очередь и объяснения, проверяют текст или скриншот без сохранения. Изменение решений, настроек и стартовых точек поиска запрещено сервером. Синтетические материалы сохраняют метку «демо»; реальные находки имеют отдельное происхождение.

`SAFENET_DATA_DIR` позволяет явно переопределить каталог состояния. Без Volume данные в контейнере не гарантированно сохраняются после развёртывания. Модель и метрики читаются из репозитория независимо от каталога состояния.

## Что доступно в облаке

- Интерфейс, объяснимый анализ текста, пакетный API и OCR скриншотов в браузере.
- Поиск публичных Telegram-каналов и очередь ручной проверки, если Telegram доступен из региона сервиса. Неудачные запросы видны в журнале.
- Поиск Instagram/TikTok по умолчанию выключен. Для открытия профилей нужен Chrome/Chromium на сервере; стандартная сборка Railpack его не устанавливает. Капча и требование входа останавливают проверку, обхода нет.
- Локальные Ollama/Whisper и захват медиа расширением не переносятся в Railway автоматически. Расширение настроено на локальный сервер. Доступность этих функций показана в интерфейсе; облачная версия не обещает анализ полного видео.

После развёртывания проверить загрузку интерфейса, `/api/health`, `/api/metrics`, одну ручную проверку и сохранение решения после перезапуска приватного сервиса. Зафиксировать URL и deployment ID только после успешной проверки.

Справка Railway: [переход на Infrastructure as Code](https://docs.railway.com/infrastructure-as-code#migrating-from-config-as-code), [Volumes](https://docs.railway.com/guides/volumes).
